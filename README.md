# DriveFleet

**Live Site:** https://drivefleet-client-jade.vercel.app/

A full-stack car rental platform where users can explore available cars, view details, book vehicles, manage their bookings, and list their own cars for rent.

## Features

- Browse and search available cars with filtering by car type
- Secure authentication with JWT stored in HTTPOnly cookies
- Add, update, and delete your own car listings
- Book a car with driver preference and special notes
- Track all your bookings in one place
- Dark mode toggle for comfortable browsing
- Fully responsive design across mobile, tablet, and desktop

## Tech Stack

- **Client:** Next.js, Tailwind CSS
- **Server:** Node.js, Express.js
- **Database:** MongoDB
- **Auth:** JWT with HTTPOnly cookies
